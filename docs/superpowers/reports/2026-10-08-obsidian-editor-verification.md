## 本轮被失败测试捕获并修复的边界

1. CMS 原读取、写出、保存前字符串裁剪和本地文件读取归一化：针对专用格式保留原文，其他格式沿用上游行为。
2. 异步图片插入位置跟踪输入变化；换文章或变为只读则取消，失败不插入失效目标。
3. 新自定义 Markdown 字段没有被 CMS 原富文本媒体逻辑识别，保存的空格/括号文件名未编码：接入原编码路径。
4. CRLF 文档接受外部 LF 时，旧换行配置把多行当成单行：传入明确的 CodeMirror Text 行结构。
5. LF/CRLF 折叠插入的光标偏移错误：按实际前缀长度定位，保留原换行风格。
6. CMS 只读权限可能被模式切换覆盖：权限与显示模式共同控制 editable/readOnly。
7. 输入导致未变预览 DOM 重建、公式失去复用：复用原节点，并更新点击定位范围。
8. 预览继承源码区的 `break-spaces`，额外显示普通软换行和空白：只读块使用正常空白规则，代码块保留原 pre 行为，正文不改写。
9. 重型语言包虽非必要仍提前打包：保留 Markdown 语法支持，许可及依赖清单按实际输出模块生成。
10. 实际 MathJax 字符串转换返回 CHTML，但不会自动插入样式；辅助 MathML 文本曾掩盖零宽字形：共享队列显式挂载可信渲染样式，实浏览器断言全部 10 个 CHTML 字形可见且安全 HTTPS 链接有尺寸。

## 独立审查

独立子代理完成全分支只读审查，发现五项边界，均已核实并修复：

1. MathJax 输出绕过原 Markdown 消毒，危险 href 可执行：后台启用 [MathJax 3.2 ui/safe](https://docs.mathjax.org/en/v3.2/options/safe.html)，转换后、缓存前再次 DOMPurify 消毒，保留实际公式字形和安全链接。
2. 多文档共用 runtime 时转换重叠及 TeX 宏泄漏：按 runtime 维护串行队列，换文档重建 InputJax；销毁中的旧任务也等待完成再开启新任务，真实宏隔离测试通过。
3. 初始化失败后的 textarea 没同步外部正文和只读状态：统一 fallback 更新/销毁接口；干净状态同步、未提交冲突提示并要求明确采用外部版本，不静默覆盖。
4. 分块预览丢失全局引用式链接/图片定义：传递全文 references，referenceKey 改变刷新预览；实际 Chrome 验证编辑另一块的定义后链接更新。
5. collapse 扫描器错误解释缩进代码中的结束标签：保护四空格代码，回归测试覆盖。

追加窄范围独立复查未发现这五项修复遗留 Important/Critical，原发现已关闭。前一次中断的审查未当作通过。本报告的自动化数量由主线程真实执行，不是代理估计。
