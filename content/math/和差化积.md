### 一、 核心公式

$$\sin\alpha + \sin\beta = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$$

$$\sin\alpha - \sin\beta = 2\cos\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$$

$$\cos\alpha + \cos\beta = 2\cos\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$$

$$\cos\alpha - \cos\beta = -2\sin\frac{\alpha+\beta}{2}\sin\frac{\alpha-\beta}{2}$$

> **注意**：第四个公式（余弦减余弦）右侧带有一个负号，这是在记忆和符号推演中最容易出错的地方。

### 二、 推导思路与举一反三

面对复杂的数学推导，死记硬背公式往往不够可靠。和差化积公式实际上是由**两角和与差的三角函数展开公式**通过换元推导而来的。掌握这个思路，不仅能在遗忘时迅速在草稿纸上复现，还能自然地理解积化和差的过程。

以推导 $\sin\alpha + \sin\beta$ 为例，过程如下：

1. 写出正弦的两角和与两角差公式：

$$\sin(x+y) = \sin x\cos y + \cos x\sin y$$

$$\sin(x-y) = \sin x\cos y - \cos x\sin y$$

2. 将两式相加，消去后半部分，得到（这同时也是积化和差公式的基础）：

$$\sin(x+y) + \sin(x-y) = 2\sin x\cos y$$

3. 引入换元，令 $x+y = \alpha$ 且 $x-y = \beta$。解这个线性方程组，可得：

$$x = \frac{\alpha+\beta}{2}$$

$$y = \frac{\alpha-\beta}{2}$$

4. 将换元后的 $x$ 和 $y$ 代回第 2 步的等式中，即得到最终的公式：

$$\sin\alpha + \sin\beta = 2\sin\frac{\alpha+\beta}{2}\cos\frac{\alpha-\beta}{2}$$

其余三个公式的推导逻辑完全平行：

- 利用两式相减 $\sin(x+y) - \sin(x-y)$ 即可推导 $\sin\alpha - \sin\beta$ 。
- 运用 $\cos(x+y)$ 与 $\cos(x-y)$ 相加，即可推导 $\cos\alpha + \cos\beta$ 。
- 运用 $\cos(x+y)$ 与 $\cos(x-y)$ 相减，即可推导 $\cos\alpha - \cos\beta$ 。

### 三、 运算策略

在处理数学分析中的极限、反常积分或判断级数敛散性时，通常有以下规律：

- 若被积函数或通项是三角函数的加减法，优先尝试**和差化积**，以凑出乘积的形式，从而方便约分、化简或应用分部积分。
- 若是三角函数的乘积，则常使用**积化和差**（即上述推导中第 2 步的逆向思维），将其拆分为独立的项，以便逐项求积分或求和。

积化和差公式同样有四个，它们的作用正好与和差化积相反，是将三角函数的乘积转化为和与差的形式。这在微积分（尤其是求解三角函数乘积的积分）以及傅里叶级数展开中非常常用。

### 一、 核心公式

$$\sin\alpha\cos\beta = \frac{1}{2}[\sin(\alpha+\beta) + \sin(\alpha-\beta)]$$

$$\cos\alpha\sin\beta = \frac{1}{2}[\sin(\alpha+\beta) - \sin(\alpha-\beta)]$$

$$\cos\alpha\cos\beta = \frac{1}{2}[\cos(\alpha+\beta) + \cos(\alpha-\beta)]$$

$$\sin\alpha\sin\beta = -\frac{1}{2}[\cos(\alpha+\beta) - \cos(\alpha-\beta)]$$

> **注意**：与和差化积公式类似，第四个公式（正弦乘正弦）的右侧同样带有一个负号。你可以将这两组公式中的“异类”（带负号的那个）联系起来记忆。

### 二、 推导思路与举一反三

正如我在上一个回答中提到的，积化和差其实就是和差化积推导过程的**逆推**，或者说是两角和与差公式的直接加减。掌握这个推导，你就不需要死记硬背这四个式子。

以推导 $\sin\alpha\cos\beta$ 为例：

1. 写出正弦的两角和与两角差公式：

$$\sin(\alpha+\beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$$

$$\sin(\alpha-\beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta$$

2. 将两式直接相加，右侧的 $\cos\alpha\sin\beta$ 项相互抵消，得到：

$$\sin(\alpha+\beta) + \sin(\alpha-\beta) = 2\sin\alpha\cos\beta$$

3. 等式两边同除以 $2$ ，即可得到第一个公式：

$$\sin\alpha\cos\beta = \frac{1}{2}[\sin(\alpha+\beta) + \sin(\alpha-\beta)]$$

其余公式的推导同理：

- 将上述两式**相减**，即可得到 $\cos\alpha\sin\beta$ 的公式。
- 将余弦的和差公式 $\cos(\alpha+\beta)$ 与 $\cos(\alpha-\beta)$ **相加**，即可得到 $\cos\alpha\cos\beta$ 的公式。
- 将余弦的和差公式 $\cos(\alpha+\beta)$ 与 $\cos(\alpha-\beta)$ **相减**，即可得到 $\sin\alpha\sin\beta$ 的公式（负号正是由余弦展开式中的减号产生的）。

### 三、 运算策略与应用场景

在数学分析或微积分中，遇到以下情况应立即联想积化和差公式：

- **计算积分**：当你需要求解形如 $\int \sin(ax)\cos(bx) dx$ 的不定积分或定积分时，直接积分通常很困难。使用积化和差将其拆分为 $\frac{1}{2} \int [\sin((a+b)x) + \sin((a-b)x)] dx$ ，就能直接应用基本积分表得出结果。
- **计算级数或求和**：在处理某些三角级数相乘的问题时，化积为和可以帮助你发现项与项之间的抵消规律（类似于裂项相消法）。
