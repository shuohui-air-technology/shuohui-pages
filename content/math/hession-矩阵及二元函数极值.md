## 1. Hessian 矩阵的定义

对于二元函数 \(f(x,y)\)，若二阶偏导数连续，则 Hessian（海森）矩阵为：

\[
\boxed{
H=
\begin{pmatrix}
f_{xx}&f_{xy}\\
f_{xy}&f_{yy}
\end{pmatrix}
}
\]

其中：

- \(f_{xx}\)：沿 \(x\) 方向的二阶变化。
- \(f_{yy}\)：沿 \(y\) 方向的二阶变化。
- \(f_{xy}\)：两个变量之间的混合变化。

**作用：通过函数在某点的二阶变化，判断该点是否为局部极值点。**

## 2. 极值判别条件

**第一步：求驻点**

令一阶偏导数为零：

\[
\boxed{
\begin{cases}
f_x(a,b)=0\\
f_y(a,b)=0
\end{cases}
}
\]

求得候选点 \((a,b)\)。

**第二步：计算 Hessian 矩阵**

在驻点 \((a,b)\) 处，记：

\[
A=f_{xx}(a,b),\quad
B=f_{xy}(a,b),\quad
C=f_{yy}(a,b)
\]

\[
H=
\begin{pmatrix}
A&B\\
B&C
\end{pmatrix}
\]

计算行列式：

\[
\boxed{D=\det(H)=AC-B^2}
\]

**第三步：判断极值**

| 条件 | 结论 |
|---|---|
| \(D>0,\ A>0\) | 严格局部极小值 |
| \(D>0,\ A<0\) | 严格局部极大值 |
| \(D<0\) | 鞍点，不是极值 |
| \(D=0\) | 无法判断，需进一步分析 |

**注意：** 判别法要求函数在驻点邻域内具有连续二阶偏导数；\(D=0\) 不代表没有极值。

## 3. 判别法的数学原理

在驻点处，由于一阶偏导数均为零，二阶泰勒展开可写成：

\[
\Delta f=
\frac12\left(Ah^2+2Bhk+Ck^2\right)
+o(h^2+k^2)
\]

其中：

\[
h=x-a,\qquad k=y-b
\]

二次型：

\[
q(h,k)=Ah^2+2Bhk+Ck^2
\]

决定函数在驻点附近的主要变化趋势。

当 \(A\ne0\) 时，配方得到：

\[
\boxed{
q(h,k)=
A\left(h+\frac BA k\right)^2
+\frac{D}{A}k^2
}
\]

因此：

- **正定**：\(q>0\)，附近函数值增加，局部极小。
- **负定**：\(q<0\)，附近函数值减少，局部极大。
- **不定**：\(q\) 有正有负，不存在局部极值。
- **半正定或半负定**：二阶项可能为零，通常需要进一步分析高阶项。

这里的正定和负定均针对所有非零位移 \((h,k)\)，高阶余项不会改变正定或负定情况下充分靠近驻点时的符号。

## 4. 计算示例

求：

\[
f(x,y)=x^2-xy+y^2-2x+y
\]

的极值。

**① 求驻点**

\[
\begin{cases}
f_x=2x-y-2=0\\
f_y=-x+2y+1=0
\end{cases}
\]

解得：

\[
\boxed{(x,y)=(1,0)}
\]

**② 计算 Hessian 矩阵**

\[
f_{xx}=2,\quad f_{xy}=-1,\quad f_{yy}=2
\]

\[
H=
\begin{pmatrix}
2&-1\\
-1&2
\end{pmatrix}
\]

\[
D=2\times2-(-1)^2=3>0
\]

且：

\[
A=2>0
\]

因此 \((1,0)\) 为严格局部极小值点。

**③ 计算极值**

\[
f(1,0)=1-2=-1
\]

\[
\boxed{\text{局部极小值为 }-1}
\]

---

## 5. 使用时的注意事项

1. **先求驻点，再计算 Hessian 矩阵**，不能直接套用判别表。
2. \(D>0\) 时，还必须检查 \(A=f_{xx}\) 的正负。
3. \(D<0\) 表示鞍点，函数沿不同方向有不同的增减趋势。
4. \(D=0\) 时二阶判别法失效，不能直接得出极值结论。
5. **Hessian 判别法判断的是局部极值，不是全局最值。** 求闭区域上的最大、最小值时，还需要检查边界。
