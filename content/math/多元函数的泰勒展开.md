# 第十七章 第四节｜二元函数泰勒公式

## 一、二元函数泰勒公式

设 \(f(x,y)\) 具有足够阶数的连续偏导数，记：

\[
h=\Delta x,\qquad k=\Delta y,\qquad
D=h\frac{\partial}{\partial x}+k\frac{\partial}{\partial y}
\]

### 1. 一般形式

\[
\boxed{
f(x_0+h,y_0+k)
=\sum_{j=0}^{n}\frac{D^jf(x_0,y_0)}{j!}+R_n
}
\]

拉格朗日余项：

\[
\boxed{
R_n=\frac{D^{n+1}f(x_0+\theta h,y_0+\theta k)}{(n+1)!},
\quad 0<\theta<1
}
\]

### 2. 各阶展开

**一阶：**

\[
\boxed{Df=hf_x+kf_y}
\]

**二阶：**

\[
\boxed{
D^2f=h^2f_{xx}+2hkf_{xy}+k^2f_{yy}
}
\]

**三阶：**

\[
\boxed{
D^3f=h^3f_{xxx}+3h^2kf_{xxy}
+3hk^2f_{xyy}+k^3f_{yyy}
}
\]

**四阶：**

\[
\boxed{
\begin{aligned}
D^4f={}&h^4f_{xxxx}+4h^3kf_{xxxy}\\
&+6h^2k^2f_{xxyy}
+4hk^3f_{xyyy}+k^4f_{yyyy}
\end{aligned}
}
\]

**一般项：**

\[
\boxed{
D^nf=\sum_{j=0}^{n}\binom nj
h^{n-j}k^j
\frac{\partial^nf}{\partial x^{n-j}\partial y^j}
}
\]

同一阶的系数服从二项式定理：

\[
\begin{aligned}
(a+b)^2&:1,2,1\\
(a+b)^3&:1,3,3,1\\
(a+b)^4&:1,4,6,4,1
\end{aligned}
\]

以上混合偏导数默认满足交换次序的条件。

## 二、麦克劳林公式

令：

\[
x_0=y_0=0,\qquad h=x,\quad k=y
\]

则：

\[
\boxed{
\begin{aligned}
f(x,y)={}&f(0,0)+xf_x+yf_y\\
&+\frac{1}{2!}
(x^2f_{xx}+2xyf_{xy}+y^2f_{yy})\\
&+\frac{1}{3!}
(x^3f_{xxx}+3x^2yf_{xxy}\\
&\qquad+3xy^2f_{xyy}+y^3f_{yyy})
+\cdots
\end{aligned}
}
\]

其中所有偏导数均在 \((0,0)\) 处取值；有限阶展开需加相应余项。

## 三、泰勒公式推导

### 1. 构造辅助函数

\[
\boxed{
\varphi(t)=f(x_0+th,y_0+tk)
}
\]

其中：

\[
0\leq t\leq1
\]

因此：

\[
\varphi(0)=f(x_0,y_0)
\]

\[
\varphi(1)=f(x_0+h,y_0+k)
\]

### 2. 求导

\[
\boxed{
\varphi'(t)=hf_x+kf_y
}
\]

\[
\boxed{
\varphi''(t)=h^2f_{xx}+2hkf_{xy}+k^2f_{yy}
}
\]

\[
\boxed{
\varphi'''(t)=h^3f_{xxx}
+3h^2kf_{xxy}
+3hk^2f_{xyy}
+k^3f_{yyy}
}
\]

一般形式：

\[
\boxed{
\varphi^{(n)}(t)
=\left(h\frac{\partial}{\partial x}
+k\frac{\partial}{\partial y}\right)^n
f(x_0+th,y_0+tk)
}
\]

### 3. 代入一元泰勒公式

\[
\boxed{
\varphi(1)=\sum_{j=0}^{n}\frac{\varphi^{(j)}(0)}{j!}
+\frac{\varphi^{(n+1)}(\theta)}{(n+1)!}
}
\]

其中：

\[
0<\theta<1
\]

由此得到二元函数泰勒公式。

## 四、常见二元复合函数求导

### 1. 基本公式

若：

\[
f(x,y)=g(ax+by),\qquad u=ax+by
\]

其中 \(a,b\) 为常数。

**一阶偏导：**

\[
\boxed{
f_x=ag'(u),\qquad f_y=bg'(u)
}
\]

**二阶偏导：**

\[
\boxed{
f_{xx}=a^2g''(u),\quad
f_{xy}=abg''(u),\quad
f_{yy}=b^2g''(u)
}
\]

**高阶偏导通式：**

\[
\boxed{
\frac{\partial^{p+q}f}{\partial x^p\partial y^q}
=a^pb^qg^{(p+q)}(u)
}
\]

其中：

- \(p\)：对 \(x\) 求偏导的次数。
- \(q\)：对 \(y\) 求偏导的次数。
- \(g^{(p+q)}\)：外层函数的第 \(p+q\) 阶导数。
- \(a^pb^q\)：内层函数求导产生的系数。

### 2. 与泰勒展开的联系

例如：

\[
f(x,y)=e^{2x+3y}
\]

在原点处展开：

\[
f(0,0)=1
\]

**一阶项：**

\[
xf_x(0,0)+yf_y(0,0)=2x+3y
\]

**二阶项：**

\[
\begin{aligned}
&\frac{1}{2!}
\left[x^2f_{xx}(0,0)+2xyf_{xy}(0,0)+y^2f_{yy}(0,0)\right]\\
&=\frac{1}{2!}(4x^2+12xy+9y^2)\\
&=\frac{(2x+3y)^2}{2!}
\end{aligned}
\]

因此：

\[
\boxed{
e^{2x+3y}
=1+(2x+3y)+\frac{(2x+3y)^2}{2!}
+\frac{(2x+3y)^3}{3!}+\cdots
}
\]

**结论：** 高阶偏导通式可用于快速求出二元泰勒公式中的各阶项，无需反复求导。

## 五、常见函数麦克劳林展开

令：

\[
u=ax+by
\]

| 函数 | 麦克劳林展开 |
|---|---|
| \(e^u\) | \(\displaystyle\sum_{n=0}^{\infty}\frac{u^n}{n!}\) |
| \(\ln(1+u)\) | \(\displaystyle\sum_{n=1}^{\infty}\frac{(-1)^{n-1}u^n}{n}\) |
| \(\sin u\) | \(\displaystyle\sum_{n=0}^{\infty}\frac{(-1)^nu^{2n+1}}{(2n+1)!}\) |
| \(\cos u\) | \(\displaystyle\sum_{n=0}^{\infty}\frac{(-1)^nu^{2n}}{(2n)!}\) |
| \(\frac{1}{1-u}\) | \(\displaystyle\sum_{n=0}^{\infty}u^n\) |
| \(\frac{1}{1+u}\) | \(\displaystyle\sum_{n=0}^{\infty}(-1)^nu^n\) |
| \((1+u)^\alpha\) | \(\displaystyle\sum_{n=0}^{\infty}\binom{\alpha}{n}u^n\) |
| \(\arctan u\) | \(\displaystyle\sum_{n=0}^{\infty}\frac{(-1)^nu^{2n+1}}{2n+1}\) |

**收敛范围：**

- \(e^u,\sin u,\cos u\)：\(u\in\mathbb R\)。
- 其余级数在 \(|u|<1\) 内成立；若 \(\alpha\) 为非负整数，二项式展开为有限多项式。

### 本节典型展开

**1. 指数函数**

\[
\boxed{
e^{x+y}
=\sum_{n=0}^{\infty}\frac{(x+y)^n}{n!}
}
\]

即：

\[
e^{x+y}
=1+(x+y)+\frac{(x+y)^2}{2!}
+\frac{(x+y)^3}{3!}+\cdots
\]

**2. 对数函数**

\[
\boxed{
\ln(1+x+y)
=\sum_{n=1}^{\infty}
\frac{(-1)^{n-1}(x+y)^n}{n}
}
\]

即：

\[
\ln(1+x+y)
=(x+y)-\frac{(x+y)^2}{2}
+\frac{(x+y)^3}{3}-\cdots
\]

收敛条件：

\[
|x+y|<1
\]

## 六、常见高阶导数

令：

\[
u=ax+by
\]

对于：

\[
f(x,y)=g(u)
\]

有：

\[
\boxed{
\frac{\partial^{p+q}f}{\partial x^p\partial y^q}
=a^pb^qg^{(p+q)}(u)
}
\]

常见外层函数的高阶导数如下：

| \(g(u)\) | \(g^{(n)}(u)\)，\(n\geq1\) |
|---|---|
| \(e^u\) | \(e^u\) |
| \(e^{cu}\) | \(c^ne^{cu}\) |
| \(\ln(1+u)\) | \(\displaystyle\frac{(-1)^{n-1}(n-1)!}{(1+u)^n}\) |
| \(\frac{1}{1-u}\) | \(\displaystyle\frac{n!}{(1-u)^{n+1}}\) |
| \(\frac{1}{1+u}\) | \(\displaystyle\frac{(-1)^nn!}{(1+u)^{n+1}}\) |
| \((1+u)^\alpha\) | \(\displaystyle\alpha(\alpha-1)\cdots(\alpha-n+1)(1+u)^{\alpha-n}\) |
| \(\sin u\) | \(\displaystyle\sin\left(u+\frac{n\pi}{2}\right)\) |
| \(\cos u\) | \(\displaystyle\cos\left(u+\frac{n\pi}{2}\right)\) |

以上公式在相应函数及导数有定义的区域内使用。
